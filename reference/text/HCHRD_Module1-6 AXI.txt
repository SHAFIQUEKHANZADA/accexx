2. Activity — Feedback & Recognition Redesign Worksheet
Instructions: Redesign a real feedback or recognition system so it reinforces specific, real behaviors tied to the organization's actual values — not generic praise.
The feedback or recognition system I'm redesigning:
As it currently exists, what does it actually reward? (Be honest — often it's visibility or seniority, not the stated values.)
Which specific value or behavior should this system be reinforcing instead?
My redesign — how will it recognize that specific behavior, specifically and consistently?
3. Quiz
A short knowledge check (5 questions) on what makes recognition systems actually reinforce culture versus just feel nice.
Sample Questions
• 1. "Great job, everyone!" sent to the whole team after a launch is an example of: (a) specific, behavior-reinforcing recognition (b) generic recognition (c) belief-level feedback
• 2. Recognition that reinforces culture should be: (a) frequent and vague (b) specific, tied to an actual behavior, and consistent (c) reserved only for top performers
• 3. A recognition system that only ever highlights individual achievement, in a culture that claims to value collaboration, is: (a) aligned (b) misaligned (c) irrelevant to culture
• 4. True or False: Recognition tied to visibility (who presents in meetings) tends to reward confidence more than the actual value being claimed.
• 5. The best test of a recognition system is: (a) how often it's used (b) whether it would still make sense if a new hire saw it with zero context (c) how much it costs
Followed by submission of the completed redesign worksheet above.
