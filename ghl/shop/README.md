# Accexx shop page for GHL (shop.accexxinsight.com)

Clean replacement for the old one-file shop code. Each file is one **Custom Code** element in the GHL page builder.

## How to paste

1. **Back up** the current page (or duplicate it) before changing anything.
2. In the page settings, turn **off** GHL's own header and footer (these blocks include their own).
3. Paste `00-global-styles.html` into **Page Settings → Tracking Code → Header Code**.
   (Or paste it as the first Custom Code element on the page.) Every other block needs it.
4. Add one **full-width section** per block, with **zero padding**, and paste one file into a Custom Code element in each, in this order:

| Order | File | What it is |
|---|---|---|
| 1 | `01-header.html` | Logo, menu (links to www.accexxinsight.com), Call Now, Join the Circle |
| 2 | `02-hero.html` | Dr. A + both books, "Every Page. A New Possibility.", Read. Imagine. Become. #R.I.B |
| 3 | `03-swag-intro.html` | "Wear the mindset. Live the message." + My Home / My Work / My Universe |
| 4 | `04-catalog.html` | All 26 products with collections, filters, sort and Buy buttons |
| 5 | `05-inside-the-pages.html` | Inside the Pages with Dr. A |
| 6 | `06-conference.html` | Why Move My Cheese? Leadership Conference band |
| 7 | `07-accexx-circle.html` | Join the Accexx Circle (GHL form `P5jS8GT6YsAX51P27C9T`) + Contact card |
| 8 | `08-footer.html` | Footer |

5. **Save**, then check the **published/preview page** (the builder canvas doesn't always run scripts).

## Turning on "Buy now" for a product

Open `04-catalog.html`, scroll to the script at the bottom, and paste the product's GHL payment link into `ACCEXX_LINKS`:

```js
"why-move-my-cheese": "https://link.fastpaydirect.com/payment-link/....",
```

A product with a link shows a gold **Buy now** button; without one it shows **Coming soon**.
Currently linked: *The Unfinished Leader (Paperback)* only.

## Notes

- Images load from the website (`https://accexx-xi.vercel.app/images/...`). Keep that site up, or upload the images to GHL Media Storage and replace the URLs.
- Prices are copied from the website's product data as of 2026-10-09. Items marked "Price coming soon" have no confirmed price. Change a price by editing its card in `04-catalog.html`.
- Form fields inside the Accexx Circle form are styled in GHL's Form Builder; page CSS cannot restyle the form iframe.
- These files are generated by a script from the website's product data; regenerate rather than hand-editing if many products change.
